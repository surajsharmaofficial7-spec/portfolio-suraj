SETUP (sirf 3 steps)
1. Node.js install karo: https://nodejs.org (LTS)
2. Is folder me terminal kholo, aur chalao:
     npm install
     npm run dev
3. Browser me kholo: http://localhost:3000

WordPress connect karna ho to .env.local me WP_GRAPHQL_URL likho,
jaise: WP_GRAPHQL_URL=https://cms.yoursite.com/graphql
Fir terminal band karke dobara "npm run dev" chalao.
